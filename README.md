### ⚡ [ESP32 Distributed Neural Network Accelerator](https://github.com/Udaykiranjammula-alpha/esp32-distributed-ml-accelerator)

<div align="center">

![Stars](https://img.shields.io/github/stars/Udaykiranjammula-alpha/esp32-distributed-ml-accelerator?style=for-the-badge&color=ec4899&logo=github&logoColor=white&label=Stars)
![Last Commit](https://img.shields.io/github/last-commit/Udaykiranjammula-alpha/esp32-distributed-ml-accelerator?style=for-the-badge&color=8b5cf6&logo=git&logoColor=white&label=Last+Commit)
![Language](https://img.shields.io/github/languages/top/Udaykiranjammula-alpha/esp32-distributed-ml-accelerator?style=for-the-badge&color=06b6d4&logo=cplusplus&logoColor=white)

</div>

> **Distributed INT8-quantized deep neural network inference across a mesh of networked ESP32 microcontrollers — no cloud, no GPU, no compromise.**

<details>
<summary><strong>🔬 Click to Expand — Distributed Cluster Topology & Ring Buffer Protocol</strong></summary>

<br/>

```
  ┌─────────────────────────────────────────────────────────────────┐
  │            ESP32 DISTRIBUTED TENSOR MESH — NODE TOPOLOGY        │
  └─────────────────────────────────────────────────────────────────┘

         ┌──────────────┐
         │  NODE 0      │  ← Master / Tensor Graph Scheduler
         │  Layer 1–3   │     Partitions model layers by SRAM budget
         │  SRAM: 520KB │
         └──────┬───────┘
                │  Wi-Fi / ESP-NOW high-throughput mesh
        ┌───────┴───────┐
        │               │
  ┌─────▼──────┐  ┌─────▼──────┐
  │  NODE 1    │  │  NODE 2    │   ← Worker nodes (INT8 matrix exec)
  │  Layer 4–6 │  │  Layer 7–9 │
  │  SRAM: 520K│  │  SRAM: 520K│
  └─────┬──────┘  └──────┬─────┘
        └───────┬─────────┘
                │
         ┌──────▼───────┐
         │  NODE 3      │  ← Aggregator / Output Layer
         │  Layer 10–12 │     Collects activations, runs softmax
         └──────────────┘

  RING BUFFER SYNCHRONIZATION:
  ┌──────────────────────────────────────────────────────┐
  │  Zero-copy activation exchange via DMA-style staging │
  │  Node N writes → shared ring slot → Node N+1 reads  │
  │  Latency: ~1.2ms per activation tensor transfer     │
  └──────────────────────────────────────────────────────┘
```

</details>
