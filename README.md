### 🔍 [FileDNA 2.0 — Digital Forensics & File Intelligence Engine](https://github.com/Udaykiranjammula-alpha/file-dna)

</div>

> **Privacy-first, fully offline, zero-telemetry digital file forensics and binary anomaly detection ecosystem for Windows & Android — engineered in Electron, Node.js and native Android M3.**

**🧮 Core Algorithmic Architecture**

| Engine | Description |
| :--- | :--- |
| **Shannon Entropy Profiler** | Computes byte-level mathematical randomness `H(X) ∈ [0.0, 8.0 bits/byte]` — distinguishes sparse padding, human-readable source, native binaries, packed payloads, and cryptolocker streams in milliseconds. |
| **Magic Byte Verification Engine** | Cross-validates binary header signatures across **30+ file format specs**. Instantly flags double-extension spoofing, disguised executables, and malformed container headers. |
| **Concurrent Multi-Hash Streamer** | Non-blocking I/O pipeline computing **SHA-256, MD5, SHA-1 & CRC-32** in parallel with constant memory footprint — no temporary disk writes. |
| **Hex Inspection & Duplicate Vault** | Raw byte-offset inspection at the page level + byte-perfect duplicate isolation regardless of filename or directory depth. |

### ⚡ [ESP32 Distributed Neural Network Accelerator](https://github.com/Udaykiranjammula-alpha/esp32-distributed-ml-accelerator)

</div>

> **Distributed INT8-quantized deep neural network inference across a mesh of networked ESP32 microcontrollers — no cloud, no GPU, no compromise.**

**🔩 Core Algorithmic Architecture**

| Engine | Description |
| :--- | :--- |
| **INT8 Tensor Partitioner** | Splits layer-wise tensor graphs across networked nodes based on SRAM budgets and network latency profiles. |
| **Ring Buffer Node Synchronization** | Zero-copy activation exchange across ESP32 cores via high-throughput low-latency mesh protocol with ring buffer DMA-style staging. |
| **Constrained Matrix Executor** | Parallel INT8 matrix multiplication engine tuned for the ESP32's 520KB SRAM, maximizing throughput per clock cycle. |
| **Fault-Tolerant Node Registry** | Automatic node discovery, health check, and workload redistribution on node failure. |
